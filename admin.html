دليل استعادة الرمز السري

Firebase لا يسمح للأدمن بتغيير كلمة مرور أي مستخدم مباشرة. الحل: حذف الحساب القديم ثم إنشاء جديد تلقائياً.
1

استقبل الطلب

الزبون يراسلك على واتساب: "نسيت رمزي، رقمي 0959xxxxxxx"

2

افتح Firebase Console

اضغط زر Firebase Console → Authentication → Users

3

ابحث عن البريد الداخلي

البريد الداخلي = رقم الهاتف (بدون 0 وبدون +963) + @ashour.local

مثال: 0959248901 → 959248901@ashour.local

4

احذف الحساب

بجانب البريد، اضغط ⋮ → Delete account

5

أخبر الزبون

"افتح التطبيق، أدخل رقمك والرمز الجديد واضغط دخول" → سيُنشأ حساب جديد تلقائياً

بيانات الزبون محفوظة: الطلبات والاسم والمحل تبقى في Firestore حتى بعد حذف الحساب.
